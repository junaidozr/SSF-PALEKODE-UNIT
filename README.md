# SSF Palekode Unit — Premium Website

A responsive React + Vite website designed with a custom emerald, ivory and lime palette.

## Run locally
1. Install Node.js (LTS).
2. In this folder run `npm install`
3. Run `npm run dev`
4. Open the local URL shown by Vite.

## Build
Run `npm run build`. The production output is in `dist/`.

## Deploy to Vercel
1. Upload this folder to a new GitHub repository.
2. In Vercel choose **Add New → Project**, import that repository.
3. Vercel detects Vite automatically. Build command: `npm run build`; output directory: `dist`.
4. Click Deploy.

## Before publishing — edit placeholders
- `src/main.jsx`: verify all unit details and copy.
- Replace the three leadership names and initials.
- Replace placeholder upcoming programme content with confirmed event details.
- Replace `hello@example.com` and the mailto link with the official email.
- Add verified phone, exact address, and real social profile URLs.
- Replace social links currently pointing to `#contact`.
- Check photo permissions and add approved photos if desired.

No secret keys or credentials are required for this static site.
